# 🧾 InvoiceCraft

## 📖 Description

**InvoiceCraft** is a modern, client-side React application for generating and downloading professional invoices as PDFs. It features a live preview, a customizable form, and local storage support so your invoice data persists between sessions. It is designed with clarity and efficiency in mind, offering both dark and light modes for an optimal user experience.

---

## ✨ Features

- 🎯 **Live Preview** – See changes immediately as you type.
- 📄 **PDF Export** – Easily download your invoices as high-quality PDFs.
- 🌓 **Dark/Light Mode** – Toggle between visual modes to suit your preference.
- 💾 **Local Persistence** – Your invoice data is automatically saved to local storage.
- ⚡ **Built with React & Vite** – Fast performance and instant feedback.

---

## 🛠️ Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (Latest LTS recommended)

### Installation
1. **Clone the repository** (if applicable) or enter the project directory.
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Run the development server**:
   ```bash
   npm run dev
   ```
